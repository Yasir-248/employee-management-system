# Employee Management System

A full-stack Employee Management System built with React, Spring Boot, and MongoDB. The application provides employee CRUD operations, search, filtering, pagination, input validation, and REST API documentation.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript and CSS

### Backend
- Java 21
- Spring Boot
- Spring Data MongoDB
- Maven
- Jakarta Bean Validation
- Springdoc OpenAPI / Swagger UI
- JUnit 5 and Mockito

### Database
- MongoDB

## Features

- Create, view, update, and delete employee records
- Search employees by name or email
- Filter by department and employment status
- Paginated employee directory
- Employee details and editing forms
- Input validation and duplicate employee checks
- REST API documentation through Swagger UI
- Service-layer unit tests

## Prerequisites

Install the following:
- Java 21 or a compatible version supported by the project
- Node.js and npm
- MongoDB
- Git (optional, for cloning and version control)
